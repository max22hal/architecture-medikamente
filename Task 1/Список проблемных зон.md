# Список проблемных зон
1. Отсутствует авторизация. Нет разделения ролей по ABAC или RBAC
2. Нарушен принцип минимизации данных. Пациентом предоставляется избыточный набор персональных данных
3. Присутствуют риски конфиденциальности
4. Неясно есть ли политика явного согласия на обработку и использование персональных данных
5. Отсутствуют методы защиты данных при сборе (шифрование, анонимизация, псевдоанонимизация и т.д.)
6. Не ясен жизненный цикл данных. Как происходит утилизация данных
7. Отсутствует шифрование при обмене данными
8. Есть риски утечки данных, так как все данные хранятся в незащищенном виде в одном месте
9. Отсутствует контроль за данными (протоколирование, мониторинг, аудит)
