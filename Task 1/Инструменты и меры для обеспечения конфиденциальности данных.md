# Меры обеспечения конфиденциальности данных

1. **Двухфакторная аутентификация (2FA)**  
   Реализовать двухфакторную аутентификацию при входе в систему для персонала компании с использованием одноразовых паролей (OTP).  
   **Инструмент:** Keycloak  
   **Цель:** предотвратить несанкционированный доступ в случае компрометации учётных данных.

2. **Управление доступом (RBAC)**  
   Реализовать разграничение прав доступа на основе ролей (RBAC) для сотрудников компании.  
   **Инструмент:** Keycloak  
   **Описание:** настройка ролей и политик доступа для различных категорий персонала (врачи, кассиры, склад, ресепшн и т. д.).

3. **Защита данных (шифрование, маскирование, обфускация)**  
   Реализовать комплексную защиту данных, включая:  
   - шифрование при хранении и передаче,  
   - маскирование при отображении,  
   - обфускацию для логов и тестирования.  
   Настроить ротацию ключей шифрования и хранение их в защищённом хранилище.  
   **Инструменты:** КриптоПро CSP, КриптоПро Storage, MaskPy, кастомные Python-скрипты для обфускации.

4. **Электронный документооборот (ЭДО)**  
   Внедрить электронный документооборот.  
   **Инструмент:** Диадок.Медицинский  
   **Возможности:** передача медицинских документов, подписание УКЭП, интеграция с 1С.

5. **Защищённые протоколы передачи данных**  
   Использовать безопасные каналы передачи данных.  
   **Протоколы:** HTTPS, TLS 1.2 или выше  
   **Дополнительно:** отключение слабых шифров, применение HSTS, использование доверенных сертификатов.

6. **Безопасная база данных**  
   Мигрировать на безопасную СУБД, поддерживающую функции шифрования, разграничения доступа и аудита.  
   **Инструмент:** PostgreSQL (опционально — Postgres Pro)  
   **Дополнительно:** настройка RLS, pgcrypto, аудит изменений.

7. **Мониторинг доступа к данным**  
   Внедрить систему мониторинга и аудита доступа к конфиденциальным данным.  
   **Инструменты:** ClickHouse + ELK (Elasticsearch, Logstash, Kibana)  
   **Функции:** сбор и анализ логов доступа, визуализация, оповещение об аномальной активности.
