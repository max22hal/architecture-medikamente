| Данные согласий пользователей | Требования закона (152-ФЗ)                                                                 | Шифрование (КриптоПро), версионирование, хранение в ClickHouse       |

| Данные об анализах           | Могут содержать чувствительные данные пациентов                                            | Шифрование (КриптоПро), маскирование (MaskPy), RBAC (Keycloak)       |

| ТМЦ                          | Данные об имуществе компании, могут содержать чувствительные данные                        | Обфускация значений чувствительных данных, ограничение доступа (RBAC)|
| Данные о медицинском персонале | Данные сотрудников компании                                                               | Шифрование (КриптоПро)                                               |
| Логи                         | Данные о работе системы                                                                     | Хэширование идентификаторов (SHA-256), аудит (ClickHouse, ELK)       |
